Où ?
Quel domaine ?Généraliste : toutes les études de marché. Santé : les études pour les laboratoires et les acteurs de santé. Médias : la mesure d'audience et les études médias. Qualitatif : entretiens, réunions de groupe, ethnographie. Méthodes et sondages : sondages d'opinion, études en ligne, panels.
Qui rencontrer ?Annonceurs : les entreprises qui achètent des études. Instituts : les sociétés d'études, qui réalisent les enquêtes pour leurs clients. Fournisseurs : les prestataires des instituts (panels, terrain, outils). Un salon s'affiche si ce public y vient nombreux : un chiffre ou une liste publiée le montre. Plusieurs choix possibles.
Visiter ou exposer ?Visiter : tous les salons. Chacun affiche son prix d'entrée. Exposer : seulement les salons qui ont des stands. Chacun affiche le prix de son plus petit stand.
